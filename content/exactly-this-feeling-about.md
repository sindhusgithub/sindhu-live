# About Exactly This Feeling

This is a book recommendation tool built on my own shelves, not the internet's. Every book it can suggest is one I actually own and have read — right now that's 521 books, from epic fantasy to food writing to things I picked up on a whim in Bangalore and never expected to love.

## What it does

Tell it a feeling. Not a genre, not a rating you're chasing — a feeling. "The end of a long summer." "Monsoon melancholy." "Something to stop me from setting fire to this world." It reads what you've written, works out what you're actually asking for, and returns three books:

- **Mirror** — a book that sits inside the feeling with you
- **Bridge** — a book that helps you move through it
- **Lift** — a book that points somewhere a little gentler

You don't have to use all three the same way every time. Sometimes you want to sit with something. Sometimes you want out. The spread is there so you can choose.

## How it actually works

I wanted to be upfront about this part, because it matters to me: the AI in this tool never invents a book, and it never picks one from general knowledge. It only translates your mood into a set of tags — melancholy, wintry, found-family, that kind of thing — and then plain code matches those tags against my real, hand-tagged library. The only thing the AI writes fresh each time is a one-line note on why a particular book fits what you asked for, and even that has to work from the book's actual, pre-written description. Nothing here is a hallucinated recommendation.

## Why I built this

I've spent a long time trying to describe books to people in the specific, weird way I actually think about them — not "it's a fantasy novel" but "it's the book for when you want to disappear for four hundred pages." This tool is that instinct turned into something other people can use. It's also, honestly, a way of sharing my shelves with you directly, rather than through a star rating or a genre tag.

## Who's behind it

I'm Sindhu — I write at [sindhu.live](https://sindhu.live), and by day I work in content design. This lives here as a small, ongoing project: I add books as I read them, and I'm still adjusting the tags and descriptions as I go, so if a recommendation feels off, that's a "not there yet," not a "never will be."

If a book showed up for you and it fit exactly, or exactly didn't — I'd genuinely like to know. There's a link for that below.
